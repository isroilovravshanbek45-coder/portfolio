# Tekshiruv natijalari

Sana: 2026-10-24.

- `npm run build`: TypeScript tekshiruvi va production bundle muvaffaqiyatli.
- `npm install --package-lock-only`: o‘rnatilgan 43 paket auditi, 0 ma’lum zaiflik.
- `CI=true npm test`: production preview orqali **12 ta test muvaffaqiyatli**.
- Desktop Chromium: 1440 × 1000; mobil Chromium emulyatsiyasi: iPhone 13.
- Layout chegaralari: 320, 375, 768, 1024 va 1440 px; gorizontal overflow yo‘q.
- Asosiy sahifa va loyiha dialogi: axe WCAG 2 / 2.1 / 2.2 AA avtomatik tekshiruvlarida buzilish topilmadi.
- Portfolio filtrlari, dialog, Escape, fokusni qaytarish, menyuda fokusni tutish, xizmatni oldindan tanlash, forma xatolari, xabar eksporti tekshirildi.
- Lokal rasmlar yuklanishi va sahifa JavaScript xatolari tekshirildi.
- WebGL mavjud bo‘lmagan holatda SVG fallback va ijtimoiy tarmoq placeholderlari tekshirildi.
- Desktop va mobil screenshotlar ko‘z bilan ko‘rib chiqildi.

Bu natijalar avtomatik brauzer tekshiruvlari va vizual ko‘rikni ifodalaydi. Haqiqiy portret, tijoriy ishlar va Telegram/Instagram manzillari taqdim etilmagan; ular uchun almashtirish nuqtalari hujjatlashtirilgan. Forma backendga ulanmagan, yuborishni taqlid qilmaydi.
